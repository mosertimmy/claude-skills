# motion-library (v1.0.0)

A free Claude skill by Timmy Moser (timmymoser.com).

Give Claude a reference video, screen recording or screenshots and it saves the motion as a reusable move in your own library. Then it makes videos from the library and opens a review page where you swap moves shot by shot.

It ships everything it needs: four neutral starter moves, a render engine, the review page and the scripts. No other skill is required.

## Install

**Claude app (web or desktop):** Customize > Skills > Add > Upload a skill, then pick `motion-library-v1.0.0.zip`. Needs a paid plan with Create and edit files turned on.

**Claude Code:** unzip into `~/.claude/skills/` so you end up with `~/.claude/skills/motion-library/SKILL.md`.

**Updating:** download the newer zip and upload it again. It replaces the old version.

Upload the zip as it is. Don't unzip and re-zip it inside another folder.

## Try it

Attach a reference video and say: "Add this to my motion library."

## Where your library lives

In a folder you connect, as `Motion library/`. With no folder, Claude hands you `motion-library.zip` at the end of each job. Attach it next time.
