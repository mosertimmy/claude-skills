# Claude workspace

Walks you through setting up one folder on your computer, organised with 5S, that Claude reads first on every task and saves everything into. Built for first-time users.

Includes `scripts/make_workspace.py` to create the folders in one go.

## Install

**Claude app (claude.ai):** Settings, Capabilities, Skills, upload the zip. To let Claude save to your computer, use the Claude desktop app and allow access to your Desktop when asked.

**Claude Code:** unzip into `~/.claude/skills/` so you end up with `~/.claude/skills/claude-workspace/SKILL.md`.

Do not zip the folder again inside another folder. The skill folder must sit at the top level.

## Use

Say "set up my workspace". Answer up to four quick questions, and say yes to making it automatic so Claude saves into the folder on every task. After that, say "new project", "save this" or "tidy up" whenever you need them.

## Update

Download the new zip and upload it again. It replaces the old version. Your workspace folder is not touched.
