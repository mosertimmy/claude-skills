# Changelog

## 1.0.0 (15 Nov 2026)
- First public release. Guided setup, 5S layout, save-as-you-go rules, project and chat handling, tidy-up check, bundled make_workspace.py.

## 1.1.0 (15 Nov 2026)
- Auto-save: wider trigger so the skill applies to every file task once a workspace exists, plus a standing instruction (CLAUDE.md, personal preferences or Project instructions) so every task starts from the folder.

## 1.2.0 (15 Nov 2026)
- References: anything attached or linked in a chat is copied into the workspace, logged in a References table in the project README, and read first on later tasks. Skill now triggers on adding items to a chat.
