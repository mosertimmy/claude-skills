# Chat handoff

Saves the state of unfinished work into one short file and gives you a single line to paste into your next chat. Start fresh without losing anything.

## Install

**Claude app (claude.ai):** Settings, Capabilities, Skills, upload the zip.

**Claude Code:** unzip into `~/.claude/skills/` so you end up with `~/.claude/skills/chat-handoff/SKILL.md`.

Do not zip the folder again inside another folder. The skill folder must sit at the top level.

## Use

Say "write a handoff" or "I am moving this to a new chat". Paste the last line into the new chat.

## Update

Download the new zip and upload it again. It replaces the old version.
