# Avoid AI design slop

Briefs Claude before it designs a page, slide, infographic or UI, then audits the result against 25 known AI design tells.

## Install

**Claude app (claude.ai):** Settings, Capabilities, Skills, upload the zip.

**Claude Code:** unzip into `~/.claude/skills/` so you end up with `~/.claude/skills/avoid-ai-design-slop/SKILL.md`.

Do not zip the folder again inside another folder. The skill folder must sit at the top level.

## Use

Ask Claude to design something. It briefs fonts, palette and real content first, builds, then audits.

## Update

Download the new zip and upload it again. It replaces the old version.
