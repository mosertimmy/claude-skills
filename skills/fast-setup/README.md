# fast-setup (v1.2.1)

A free Claude skill by Timmy Moser (timmymoser.com).

One guided setup for Claude: your folder, working rules, first project, apps and the other free skills. It carries the whole script, so it works with no web access.

## Install

**Claude app (web or desktop):** Customize > Skills > Add > Upload a skill, then pick `fast-setup-v1.2.1.zip`. Needs a paid plan with Settings > Capabilities > Create and edit files turned on.

**Claude Code:** unzip into `~/.claude/skills/` so you end up with `~/.claude/skills/fast-setup/SKILL.md`.

Then start a new chat and say: **Set me up with the fast setup.**

**Updating:** download the newer zip and upload it again. It replaces the old version.

Upload the zip as it is. Don't unzip and re-zip it inside another folder, or the uploader will reject it.
