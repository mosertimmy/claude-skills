# hook-ideation (v1.0.0)

A free Claude skill by Timmy Moser (timmymoser.com).

Ask for hook and format ideas for a reel, Short, TikTok or post. You get a ranked table: the on-screen hook, the format, the first 2 seconds, the footage each idea needs and why it should work.

## Install

**Claude app (web or desktop):** Customize > Skills > Add > Upload a skill, then pick `hook-ideation-v1.0.0.zip`. Needs a paid plan with Settings > Capabilities > Create and edit files turned on.

**Claude Code:** unzip into `~/.claude/skills/` so you end up with `~/.claude/skills/hook-ideation/SKILL.md`.

**Updating:** download the newer zip and upload it again. It replaces the old version.

Upload the zip as it is. Don't unzip and re-zip it inside another folder, or the uploader will reject it.

## Use it

Say "give me hook ideas for [subject]". Attach a clip or photos if you have them, and say the platform and goal if you know them.
